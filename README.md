# skylightrepo
  This is a archetecture project for modifiying a skylight to fit NM climate for optimal daylighting. Done during the Computing in Research summer internship 2026.

# Abstract 
  This project is a modification of a specific daylighting techniqe made for Portland Oragon in order for it to be functional in Santa fe New Mexico. The modifications are made based off of information found from airport data gathering, archetectural studies, the original designs research, and climate studies. This study resulted in the developmet of techniqes that can be used to further generalize and create similar designs with the same goals. The goals of this was to keep the original designs properties with new factors and climate differences. 

# Goals
  For this project the goals for the design is to have it provide a comfortable environment with its lighting and apperance while providing a energy saving and environmentally susainable alternaivs for buildings. It keeps a work room lit in a comfortable range of 20-45 foot candels for 95% of the time it is in use for in a year.
